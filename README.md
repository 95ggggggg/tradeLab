## 실행 근거의 범위

수치는 구현 원본에 보존된 기존 실행 기록이다. 이 안내 저장소를 준비하면서 애플리케이션 테스트·부하를 새로 실행하지 않았다. 과거 JUnit XML·임시 실행 폴더의 원본 전체가 이 저장소에 포함되어 있다는 뜻은 아니다. 보존된 결과 문서의 환경·명령·초기 조건·소스/JAR 식별과 테스트 코드를 함께 제시한다.

실제 증권사 주문·자금 예약·보유 자산·손익 계산은 현재 구현 범위 밖이다. Execution은 합성 이벤트의 가상 처리 기록이며 주문 상태·잔액을 갱신하지 않는다. 코드 실행 방법은 [원본 README](https://github.com/95ggggggg/invest-prj/blob/5ab986710627cd16a17b3c516959d590ce95cabd/README.md)를 따른다.
