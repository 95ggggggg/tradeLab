## 소스 버전과 실행 버전

위 링크는 검토 가능한 현재 소스를 고정한다. 9월의 Before/After 실험은 해당 결과 문서에 기록된 당시 소스·설정·JAR와 함께 읽는다. 현재 코드 커밋을 당시 모든 실행의 정확한 커밋으로 바꿔 쓰지 않는다.

결과 문서에 적힌 임시 경로·JUnit XML·부하 원본 전체의 현재 보존 여부는 별도다. 이 심사용 저장소에는 요약과 원본 코드/결과 문서의 위치를 제공하며 원본 실행 파일이 모두 첨부됐다고 주장하지 않는다.
